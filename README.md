Security research, threat intelligence, and offensive/defensive tooling maintained by the Deriv Security team.

## Overview

This repository is a working space for the security team's threat research. It collects notes, proof-of-concept code, detection rules, and analysis of vulnerabilities and adversary techniques relevant to our products and infrastructure.

## Contents

| Directory | Description |
|-----------|-------------|
| `findings/` | Write-ups of confirmed vulnerabilities and assessments |
| `pocs/` | Proof-of-concept exploits and reproduction scripts |
| `detections/` | Detection rules and hunting queries |
| `tooling/` | Internal scripts and helpers for research |
| `docs/` | Methodology, playbooks, and reference material |

## Getting Started

```bash
git clone https://github.com/deriv-security/threat-research.git
cd threat-research
```

## Contributing

1. Create a branch for your research: `git checkout -b research/<topic>`
2. Add your findings with clear reproduction steps.
3. Open a pull request for review.
