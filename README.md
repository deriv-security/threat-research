# Threat Research

Security research, threat intelligence, and offensive/defensive tooling maintained by the Deriv Security team.

## Overview

This repository is a working space for the security team's threat research. It collects notes, proof-of-concept code, detection rules, and analysis of vulnerabilities and adversary techniques relevant to our products and infrastructure.

## Responsible Disclosure

All research in this repository is for authorized, defensive, and educational purposes only. Do not use anything here against systems you are not explicitly authorized to test.
